+ The OpenTelemetry Collector offers a vendor-agnostic implementation on how to receive, process and export telemetry data. It removes the need to run, operate and maintain multiple agents, collectors, or backends in order to support open-source observability data formats (e.g. Jaeger, Prometheus, Fluent Bit, etc.) sending to one or more open-source or commercial backends.
+ Read more about the Collector in the o11y guide. This project does not ship any binaries; instead it is broken down into components that are grouped into a distribution with its own versioning and release cycle. To get started with a specific distribution, see the full list of distributions and the pre-build components.
+ The Collector features several possible deployment approaches: as an agent (running with the application or on the same host as the application), as a gateway (a standalone service typically running per cluster, virtual machine, or data center), or as both (agent and gateway).
